<product_requirements>
The Poker Chip Control application aims to be a comprehensive tool for managing poker game sessions, player transactions, and club finances. It enables users to create, manage, and close game sessions, enforcing that all players cash out. Players handle chips via various transaction types like Cash, Bank Transfer, or Credit, and divest through Cashed Out, Paid with Chips, or Pay Credit. The system tracks Total Table (chips in play), Player Profit/Loss, and Club Earnings, offering reporting and CSV export of past sessions. Key UX principles include intuitive, thumb-friendly design, a 3x2 transaction grid, large back buttons, a blue theme, and bilingual support (Spanish/English). Player profiles feature circular Base64 profile photos. The dashboard displays Debt Owed and Club Earnings, while the game screen provides a compact player UI with photo, name, balance, Chips in Game, and Total Table Amount, including visual cues for cashed-out players.
</product_requirements>
