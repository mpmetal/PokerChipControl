<product_requirements>
The application aims to manage poker games by tracking chip transactions for each player, calculating credit balances, and carrying over debts/credits to subsequent sessions. Key features include:
1.  **Game Session Management**: Create new sessions with a New Game Session button, including a game name, auto-dated. Sessions load existing players with their pending balances.
2.  **Player Operations**: Each player row must have buttons for:
    *   **Cash/Bank Transfer**: Player buys chips, no credit generated. Tracks chips in play.
    *   **Credit**: Player receives chips on credit, generates negative balance (debt).
    *   **Cashed Out**: Player converts positive balance to cash profit, credit balance becomes zero. Must reflect actual winnings, not just any amount.
    *   **Paid with Chips**: Player uses chips to pay off debt.
3.  **Closing Game Session**: Button to finalize session, calculate final balances, save debts for next session, save cashed-out profits, and store full session history.
4.  **History and Reports**: List past sessions with full details. Player reports should show total chips played, credits, payments, winnings, and accumulated debts. Data export to Excel/CSV.
5.  **User Experience (UX) Enhancements**:
    *   Player selection for games should be intuitive, not blocked by modals.
    *   Transaction buttons should be visible without horizontal scrolling (3x2 grid).
    *   Back button touch target needs to be larger.
    *   Total chips in play for the table and per player should be visible.
    *   Application theme needs to change from green to blue.
    *   Application must support Spanish and English.
    *   Player Management: Ability to edit player name, balance, delete players, and add/display circular profile photos.
    *   Logo integration: Replace main title with a provided logo and text PokerChipControl.
</product_requirements>
